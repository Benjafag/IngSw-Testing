# Instrucciones para correr los tests
Para correr todos los test


```
pytest
```

Para hacer prueba de cobertura de lineas y generar archivos html para el resumen de lineas ejecutadas


```
pytest --cov=. --cov-report=html
```

Para resumen de cobertura de lineas y ramas


```
pytest --cov=. --cov-branch
```
